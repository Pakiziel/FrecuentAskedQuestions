Sistema de Gestión de Preguntas Frecuentes

Frequent Asked Questions (FAQ) es una aplicación web diseñada para gestionar y mostrar preguntas frecuentes de manera organizada y accesible a los usuarios.
Permite visualizar preguntas de distintas categorías, mantener actualizada la información y mejorar la atención al usuario reduciendo consultas repetitivas.

✅ Visualización de preguntas frecuentes organizadas por temas
✅ Búsqueda rápida de preguntas
✅ Sección administrativa para agregar, editar o eliminar preguntas
✅ Interfaz intuitiva y amigable
✅ Diseño responsive para uso en móviles y escritorio
